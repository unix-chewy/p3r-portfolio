# Persona-Style Portfolio — Joney Sunga

A visually immersive portfolio experience inspired by the digital LCD aesthetic of *Persona 3*. This creative showcase brings my machine learning projects and personal journey to life through a menu-driven interface that channels the retro-futuristic vibe of the beloved RPG.

## What You'll See

Each screen is designed with Persona 3's iconic teal-blue digital LCD theme, featuring dynamic video backgrounds, smooth transitions, and a nostalgic yet modern feel.

## How It Works

Built as a Model–View–Controller architecture:
- **Model** (`js/model.js`): My projects, skills data, GitHub integration
- **View** (`js/view.js`): DOM rendering with ransom lettering effects, wipes, sound
- **Controller** (`js/controller.js`): Keyboard and mouse input handling

*Inspired by Persona 3 Reload*
